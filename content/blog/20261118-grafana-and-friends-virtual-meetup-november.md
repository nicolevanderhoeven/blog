I co-hosted the first online edition of the Grafana & Friends community meetup with **Ewa Magiera**, Community Manager at Grafana Labs. Three community speakers shared what they've built and learned with Grafana: **Carike Blignaut-Staden** on designing inclusive, accessible dashboards that people actually use, **Emmanuel Okororie** on building Fantasy Premier League dashboards from a JSON API with the Infinity data source and Grafana Assistant, and **Rashi Dashore** on giving an AI agent access to Grafana through MCP without handing over your API token, using Docker Sandboxes.
